🎙️ Voice Assistant in Hindi & English
Voice Assistant in Hindi & English is an AI-driven virtual assistant built with Python, designed to provide interactive support for university websites. Leveraging natural language processing (NLP), it supports multilingual (Hindi/English) speech-to-text and text-to-speech functionality. The assistant offers course details, admission support, and more, with user-preferred language interaction. Note: This project is under development with limited commands and features.

✨ Features

🗣️ Multilingual speech recognition (Hindi & English) using Google’s Web Speech API
📢 Text-to-speech responses with pyttsx3 in Hindi or English
🎓 University-focused assistance (course details, admission support)
🤖 Interactive chatbot capabilities via NLP
⚙️ Customizable language selection based on user preference
🚧 Under active development with planned feature expansions

🚀 Getting Started
Prerequisites

Python 3.8 or higher
pip for package management
A stable internet connection (for Google Web Speech API)
A microphone for voice input

Required Python libraries:
pip install speechrecognition pyttsx3

Note: For Windows, you may need to install pywin32 for pyttsx3 compatibility:
pip install pywin32

Installation

Clone the Repository:
git clone https://github.com/your-username/voice-assistant-hindi-english.git
cd voice-assistant-hindi-english


Install Dependencies:
pip install -r requirements.txt


Set Up Microphone:

Ensure your microphone is connected and functional.
Test audio input using Python’s speech_recognition module.


Run the Assistant:
python main.py


Follow the prompts to select Hindi or English.
Use voice commands to interact (e.g., ask about courses or admissions).




🛠️ Tech Stack
